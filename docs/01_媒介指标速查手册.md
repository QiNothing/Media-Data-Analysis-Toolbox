# 媒介指标速查手册

> 这份手册是给完全没接触过媒介行业的人写的。
> 建议第一天通读一遍，之后当字典查。

---

## 一、为什么电视广告要用这套指标

数字广告可以精确知道谁点了、谁买了。电视不行——你不可能知道每台电视机前坐着谁、
有没有在看广告。所以整个电视广告行业建立在**抽样调研 + 统计推算**之上。

这套指标体系解决的核心问题是：**在不能精确追踪个体的前提下，如何量化"我的广告被多少人看了多少次"。**

理解了这一点，后面所有指标就都好理解了：它们都是在回答"多少人 × 多少次"这个问题的不同侧面。

---

## 二、四个基础量

### 收视率 Rating

**定义**：某个时刻，看某个频道的人数 ÷ 目标人群总人数 × 100%

**注意单位**：行业里说"收视率 0.85"，指的是 **0.85%**，不是 85%。
一个频道能有 1% 的收视率已经相当不错了，2% 以上是爆款。

**常见错误**：源数据里有时用小数形式（0.0085）表示 0.85%。
导进来不检查，所有 GRP 会差 100 倍。工具的质检规则会抓这个。

### GRP（毛评点 / 总收视点）

```
GRP = Σ(每次播出的收视率)
```

**例**：在收视率 0.85% 的时段投 20 次，GRP = 0.85 × 20 = 17

**怎么理解这个数**：GRP 100 意味着"广告在目标人群面前平均露了 1 遍"。
注意是"平均"——可能是 100% 的人各看 1 次，也可能是 10% 的人各看 10 次。
**GRP 分不出这两种情况**，这是它最大的局限。

**GRP 可以超过 100**，而且经常超过。一个中等规模的电视 campaign 通常是 300~800 GRP。

### TRP（目标毛评点）

跟 GRP 一模一样，只是收视率算的是**目标人群**而不是全人群。

**为什么重要**：如果你的产品是母婴用品，全人群收视率高的体育频道对你没意义，
你要看的是"25-40 岁女性"这个人群的收视率。

> ⚠️ **GRP 和 TRP 绝对不能混着比。**
> 这是新人最容易犯的错误。看到一个数字，第一件事永远是问"这是什么人群口径"。

### 曝光量 Impressions

```
曝光人次 = GRP ÷ 100 × 目标人群总人数
```

**例**：GRP 100，目标人群 1.3 亿人 → 曝光 1.3 亿人次

**注意是"人次"不是"人数"**。同一个人看 3 次算 3 人次。
这也是为什么曝光量看起来总是大得吓人。

## 三、两个成本指标

### CPRP（每收视点成本）

```
CPRP = 总花费 ÷ GRP
```

**这是电视媒介最核心的一个数。** 记住它，其他都可以查。

- 跟媒体谈判：谈的就是 CPRP
- 跟客户汇报效率：报的就是 CPRP
- 判断买贵了没有：比的就是 CPRP

**比 CPRP 的三个前提**（缺一不可）：
1. 同人群口径
2. 同区域口径
3. 同时段/资源类型

拿央视黄金档和地面台日间比 CPRP，是没有意义的。

### CPM（每千人次曝光成本）

```
CPM = 花费 ÷ 曝光量 × 1000
```

**什么时候用 CPM 而不是 CPRP**：需要跨媒体比较的时候。

电视用 CPRP，数字媒体用 CPM。要把电视、OTT、信息流放在一张表里比，
只能统一换算成 CPM。

**跨媒体比 CPM 的陷阱**：各媒体对"一次曝光"的定义不一样。
电视的"收视人次"是统计推算的，信息流的"展示数"是服务器日志。
两者不完全可比，比之前要说明口径差异。

## 四、到达率与频次（最难但最重要的部分）

### 净到达率 Reach（1+ 到达率）

**定义**：至少看到 1 次广告的人 ÷ 目标人群 × 100%

关键词是**去重**。同一个人看 10 次，也只算 1 个人。

**为什么它是凹曲线**：

想象你在一个 100 人的房间里发传单。
- 第一轮随机发 50 张 → 大约覆盖 50 人
- 第二轮再发 50 张 → 但其中一半会发给已经拿过的人，只新增约 25 人
- 第三轮再发 50 张 → 新增约 12 人
- ……

**投入是线性的，覆盖是递减的。** 这就是到达率曲线的形状。

**它有天花板**：一个频道最多能覆盖多少人，取决于有多少人会打开这个频道。
CCTV-1 的天花板大约 60%，一个地面频道可能只有 15%。
**无论投多少钱，都不可能超过天花板**——这时候唯一的办法是增加媒体。

### 平均频次 Frequency

```
频次 = GRP ÷ 到达率
```

**含义**：被碰到的那些人，平均每人看了几遍。

**判断标准**：

| 频次 | 判断 | 该怎么办 |
|---|---|---|
| < 2 | 太散，记不住 | 集中投放，减少频道数 |
| 3 ~ 8 | 合理区间 | 保持 |
| > 10 | 浪费，在重复轰炸 | 增加媒体，扩大覆盖 |

### 有效到达率 nR+

**定义**：至少看到 n 次的人口占比。n 通常取 3。

**为什么需要它**：只看过 1 次广告的人，基本记不住。
行业共识是至少 3 次才算"有效触达"。

所以当客户问"到底有多少人真的记住了我的广告"，
答案不是净到达率，而是 **3+ 有效到达率**。

**n 该取几**（这个要跟客户先对齐）：

| 场景 | 建议 n | 理由 |
|---|---|---|
| 新品上市 | 5+ | 全新信息，认知门槛高 |
| 常规品牌维护 | 3+ | 行业默认值 |
| 促销告知 | 2+ | 信息简单，靠广度 |
| 品牌提醒 | 2+ | 已有认知，只需唤醒 |

## 五、跨媒体合并（多个频道加起来能覆盖多少）

**❌ 绝对不能直接相加。**

A 台到达 50%，B 台到达 50%，加起来不是 100%——
因为有一批人两个台都看，被重复计算了。

**Sainsbury 公式**（行业标准近似）：

```
合并到达率 = A + B − A × B ÷ 100
```

上例：50 + 50 − 50×50/100 = **75%**

**这个公式的假设**：两个媒体的受众相互独立。

**它的局限**：现实中受众是正相关的（爱看电视的人到处都看），
所以 Sainsbury 会**略微高估**真实净到达。

**实务做法**：对外汇报用 Sainsbury 并注明方法。要保守可以乘 0.9~0.95 系数。
如果公司有官方跨媒体去重工具，以官方为准。

## 六、声量指标（竞品分析用）

### SOV（声量份额）

```
SOV = 本品投放量 ÷ 市场总投放量 × 100%
```

投放量可以用花费，也可以用 GRP。**两者结论可能不同**——
用花费算受折扣和刊例定价影响大，用 GRP 算更接近真实曝光强度。
建议两个都算，不一致时在报告里说明。

### ESOV（超额声量）与增长法则

```
ESOV = SOV − SOM（市场份额）
```

**Binet & Field 法则**：ESOV 每高出 10 个百分点，年市场份额约增长 0.5 个百分点。

| ESOV | 含义 | 建议 |
|---|---|---|
| < 0 | 声量赤字 | 份额会被侵蚀，需要加投 |
| ≈ 0 | 声量持平 | 只能维持现状 |
| > 0 | 超额声量 | 有增长动能 |

**这是论证"为什么要加预算"最有力的工具。**

**但要诚实说明三个前提**：
1. 这是跨品类统计规律，不是精确预测
2. 前提是创意质量不显著低于竞品
3. 适用于成熟品类的份额竞争

## 七、一张图记住所有关系

```
                       预算
                        │
                     ÷ CPRP
                        ↓
                      GRP  ←── 客户最常考核这个
                        │
            ┌───────────┴───────────┐
            ↓                       ↓
        净到达率                 平均频次
      （碰到多少人）           （每人看几遍）
            │                       │
         拉新看它               记忆度看它
            │                       │
            └──────→ 3+有效到达 ←────┘
                （真正记住的人）
```

**核心洞察**：

> 预算固定时，**铺得越广就砸得越浅，砸得越深就铺得越窄**。
>
> 媒介策划的本质，就是根据营销目标决定这个平衡点往哪边偏。

## 八、口径三问（每次拿到数据必问）

1. **人群口径**：全人群（4+）还是目标人群？目标人群怎么定义的？
2. **区域口径**：全国网？城域网（哪几个城市）？省网？
3. **数据源**：CSM / 勾正 / 尼尔森？

不同源、不同口径的数据**不能相加、不能对比**。

问清这三个问题，能避免 80% 的数据事故。
不问就出报告，是新人最容易踩的坑。
