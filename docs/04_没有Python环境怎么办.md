# 公司电脑没有 Python 怎么办

> 国内职场常态：公司电脑装软件要 IT 审批、没有管理员权限、U 盘被禁用。
> 这份文档给出三条路，**按推荐顺序排**，从最省事到最受限。

---

## 先说一件不能做的事

**不要为了图方便，把这个工具部署到云端**（Streamlit Cloud、各种在线 Python 平台）。

原因：客户的投放数据、采买折扣、CPRP 都是**商业机密**。
传到公网服务器等于泄密，一旦出事，性质比"用了未审批的软件"严重得多。

这个工具的设计就是**纯本地运行、不联网、不上传任何数据**。请保持这一点。

---

## 方案一：绿色便携版（首选）

**适用**：不能装软件 / 没有管理员权限，但能往公司电脑拷文件。

### 它是什么

一个自带 Python 运行时的文件夹。**解压即用**：

- ❌ 不需要安装
- ❌ 不需要管理员权限
- ❌ 不写注册表、不改系统环境变量
- ✅ 删掉文件夹 = 卸载干净，不留任何痕迹

技术上用的是 **Python 官方的 embeddable（嵌入式）发行版** ——
这是 Python 官方专门为"嵌入到其他程序里分发"提供的版本，
本质就是一堆 dll 文件，跟绿色版软件是一个道理。

### 怎么做

**在有网的电脑上**（比如你家里这台）跑一次：

```bash
python -m tools.build_portable
```

约 5~10 分钟，产出 `dist/媒介分析工具箱_便携版/`，约 300 MB。

然后：

1. 整个文件夹拷到 U 盘 / 个人网盘
2. 在公司电脑上**完整解压**到你的个人目录（如 `D:\我的文档\`）
3. 双击 `自检.bat` —— 10 秒确认换机器后一切正常
4. 双击 `启动.bat` —— 开始用

### 注意事项

| 事项 | 说明 |
|---|---|
| **必须完整解压** | 不能在压缩包里直接双击运行，会报"找不到 python.exe" |
| **不要放 C:\Program Files\** | 那里通常需要管理员权限才能写文件，放个人目录 |
| **架构要匹配** | 打包机和公司电脑都是 64 位 Windows 就没问题（现在基本都是） |
| **杀毒软件可能误报** | 对 `python.exe` 的常见误报，把整个文件夹加白名单即可 |
| **不要传公网网盘** | 尤其是已经装了客户数据的成品 |

### 验证

打包完在自己电脑上跑一遍验证，确认成品能独立运行：

```bash
python tests/test_portable.py
```

这个测试会**清空所有 Python 相关环境变量**再跑，模拟一台从没装过 Python 的电脑。
30 项全过才算真的能用。

## 方案二：只用 Excel 模板（零依赖兜底）

**适用**：连 U 盘都禁用，只能收发邮件；或者要把测算结果发给客户/同事。

### 它能做什么

`output/excel模板/` 下的 5 个文件，**完全不需要 Python**，
可以通过邮件、企业微信、内部网盘传输，双击就能用：

| 文件 | 能力 |
|---|---|
| `1_GRP预算测算模板.xlsx` | 改预算/频道 → GRP、到达率、频次、3+有效到达全自动算，带响应曲线图；含反算 |
| `2_跨媒体组合与边际分析.xlsx` | 多频道 Sainsbury 去重、追加预算加哪里最划算 |
| `3_数据质检清单.xlsx` | 粘上数据自动标红问题行 + 交付前自查 |
| `4_媒介指标速查卡_可打印.xlsx` | A4 单页，打印贴工位 |
| `5_周报模板.xlsx` | 填数字自动出环比、KPI 达成、结论草稿 |

所有计算都是**真公式**，改输入格结果自动变。
公式经过验证，与 Python 内核的计算结果完全一致（140 项比对全过）。

### 它做不到什么

**自动预算优化器**。那个需要迭代计算（把预算切成 150 份逐份分配），
纯 Excel 公式实现不了，挂 Solver 也不如专门写的贪心算法可靠。

**变通办法**：用 `2_跨媒体组合与边际分析.xlsx` 的边际分析栏，
手动试几个分配方案，看哪个净到达率最高。
虽然不是全局最优，但对日常场景够用了 —— 边际分析已经告诉你"下一笔钱该加哪"。

### 怎么拿到这些文件

在家里的电脑上双击 `生成Excel模板.bat`，然后把 `output/excel模板/` 里的文件
发到自己的工作邮箱。

## 方案三：申请安装 Python（最省事，如果能批）

**适用**：公司允许申请装软件，只是流程走一下。

Python 是**开源免费**的，没有授权费用，也不是什么敏感软件，
很多公司的数据岗位本来就允许装。值得先问一句。

### 安装步骤（拿到权限后）

1. 到 https://www.python.org/downloads/ 下载 **Python 3.11 或 3.12**
   （不建议装最新版，部分库的预编译包可能还没跟上）

2. 运行安装程序，**务必勾选 `Add Python to PATH`**（这一步漏了后面会很麻烦）

3. 选 "Install Now" 即可，不需要改默认选项

4. 装完打开命令行验证：
   ```bash
   python --version
   ```

5. 把工具箱文件夹拷过去，双击 `启动.bat`，会自动装依赖

### 如果公司内网不能访问 pypi

依赖包装不上的话，在家里先下载好离线包：

```bash
# 在家里的电脑上
python -m pip download -r requirements.txt -d offline_packages
```

把 `offline_packages` 文件夹一起拷过去，然后在公司电脑上：

```bash
python -m pip install --no-index --find-links=offline_packages -r requirements.txt
```

## 三个方案怎么选

```
公司电脑能装软件吗？
├─ 能 ──────────────→ 【方案三】直接装 Python（最省事）
└─ 不能
    └─ 能往电脑里拷文件吗？（U盘/网盘/邮件附件）
        ├─ 能 ──────→ 【方案一】绿色便携版（推荐，功能完整）
        └─ 不能 ────→ 【方案二】只用 Excel 模板（邮件就能传）
```

**还有一个组合打法**：

平时在**家里**用完整版（网页版跑测算、出报告），
把结果导出成 Excel 带到公司；公司电脑上只用 Excel 模板做临时测算和汇报。

这样既不用折腾公司电脑，又能用上全部能力。
很多做数据的人实际上就是这么干的。

## 常见问题

**Q：便携版会不会被公司的安全软件拦截？**

有可能。部分企业安全软件会拦截"未签名的可执行文件"。
如果被拦，先跟 IT 说明情况申请加白名单；
实在不行就退回方案二（Excel 模板不会被拦，它就是普通的 xlsx 文件）。

**Q：便携版和正式安装的版本，功能有区别吗？**

没有。是完全相同的代码，只是 Python 运行时打包在文件夹里而已。

**Q：300 MB 是不是太大了，能再小吗？**

打包时已经删掉了测试文件、pip、缓存（省了 130 MB）。
剩下的主要是 pandas、numpy、plotly 这些库本身的体积，删不动了。
如果实在需要更小，可以去掉 plotly（少 55 MB），代价是网页版没有图表。

**Q：公司电脑没有 Excel，只有 WPS，模板能用吗？**

能。用到的都是标准函数（VLOOKUP、INDEX、MATCH、EXP、LN、条件格式），
WPS 都支持。个别情况下条件格式的显示可能有细微差异，但计算结果一致。

**Q：我在公司算的结果，怎么带回家继续分析？**

导出 Excel 带回去就行。但注意公司的数据外带规定 ——
**客户数据外带可能违反保密协议，这个要先问清楚**，别为了方便惹麻烦。
